# Typeset mentor reports

The 15 November 2026 PDFs are XeLaTeX editions of the [project brief](../PROJECT_BRIEF.md) and [global roadmap](../GLOBAL_EXTENSION_PLAN.md). They use A4 pages, Cambria body type, Calibri headings, vector data figures, selectable text, embedded fonts and clickable links. [All presentation downloads](../pdf/README.md).

- `project-brief.tex`: six-page complete project/research overview.
- `global-extension-plan.tex`: five-page delivered-extension and research roadmap.
- `report-style.tex`: shared page layout, typography, tables and captions.
- `build_report_figures.py`: earlier Bangladesh benchmark/ESA figures retained as historical supporting material.
- `build.py`: two-pass typesetting; rejects overfull boxes and missing glyphs.
- `figures/history-story.*` and `sensor-story.*`: current seasonal/pixel-size presentation figures, generated by the [demo builder](../submission/build.py).
- `figures/global-transfer.*`: research comparison figure retained for academic review; the public pitch uses the seasonal example.

With XeLaTeX (MiKTeX or TeX Live), the declared TeX packages, Python and matplotlib installed:

```powershell
python docs/latex/build.py
```

The authoring environment has Cambria, Calibri, Consolas and Nirmala UI. Other platforms need compatible installed fonts or deliberate font substitutions followed by visual review. The builder filters invalid PATH entries only in child processes; it does not change the user's environment or install missing TeX packages.

Output is published into `docs/pdf/`; intermediates and compiler logs remain in ignored `build/`. Inspect every page after substantive changes. A successful compile cannot detect every awkward layout or an unsupported scientific claim. The seven-slide deck and 29-second video have separate [build instructions](../submission/README.md).
