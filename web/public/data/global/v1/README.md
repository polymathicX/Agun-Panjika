# Development experiment archive

These are the initial development experiment results, recorded on 14 November 2026: fit 2013–2018, interval calibration 2019–2021, test 2022–2024. The observations and results are retained for comparison with the final annual workflow.

Shared feature files are in [../features/](../features/). Their checksums are recorded in each original case JSON. The original implementation is available at Git commit `a893739`; the current implementation and [model card](https://github.com/polymathicX/Agun-Panjika/blob/main/docs/GLOBAL_EVALUATION.md) describe the new workflow and its limitations.
